# Repo van de Brigadiers

## Backend:
- Programmeertaal: C#
- Framework: http://ASP.NET 8.0 Core
- ORM: Entitiry Framework Core (LINQ; eenvoudig manier om objecten DB te maken)
- Database: MS SQL (Server based op cloud)

## Frontend:
- Framework: React
- Programmeertaal: JavaScript/TypeScript
- Bootstrap/Tailwind?
- WCAG 2.1

# Testing & Quality:
- Specflow C# (BDD Testing)
- Cypress (end-to-end testing)

# Overige Eisen:
- Backend en frontend moeten goed met elkaar communiceren via API’s
- Beveiliging minimaal AVG-proof (HTTPS, versleuteling, etc.)
- Makkelijk uitbreidbaar
- Compatibel met meeste browsers
- Responsief, tekst, tekst boxes, etc schalen naar de juiste beeldscherm formaat.
